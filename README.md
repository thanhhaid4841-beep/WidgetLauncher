# Widget Launcher
Launcher Android: lưới widget 4x7, kéo thả, đổi cỡ, tự sắp xếp, ngăn ứng dụng có tìm kiếm.
## Lấy file APK (không cần cài Android Studio)
1. Tạo repo mới trên GitHub, upload toàn bộ thư mục này (giữ cả thư mục .github).
2. Vào tab Actions > "Build APK" > đợi ~3-5 phút.
3. Mở lần chạy xong > mục Artifacts > tải "WidgetLauncher-apk" > giải nén lấy app-debug.apk.
4. Cài APK trên điện thoại (cho phép cài từ nguồn không rõ), nhấn nút Home và chọn "Widget Launcher" > "Luôn dùng".
## Cách dùng
- Nhấn "＋ Widget" hoặc nhấn giữ chỗ trống để thêm widget.
- Nhấn giữ widget để vào chế độ chỉnh: kéo để di chuyển, ↔/↕ đổi cỡ, 🗑 xóa, ✓ xong.
- "✨ Sắp xếp" tự xếp gọn; "⊞ Ứng dụng" mở danh sách app.
